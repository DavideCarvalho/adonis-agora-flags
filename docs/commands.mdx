| Command | What it does |
|---|---|
| `flags:list [--env] [--json]` | Every flag: declared type and default, what it serves, owner |
| `flags:set <flag> <value> [--env] [--note] [--as]` | `on`, `off`, `kill`, `unkill`, `25%`, a variant name, or a value (`flags:set max_uploads 25`, JSON for JSON flags) |
| `flags:types [--env] [--out] [--no-strict]` | Generate TypeScript types for the flags created in the console |
| `flags:work [--once] [--sink]` | Run background work: relay, schedules, results, maintenance |
| `flags:results <experiment> [--fresh]` | Experiment results |
| `flags:requests [list\|approve\|reject\|cancel] [id] [--note]` | Change requests |
| `flags:export [--env] [--out]` | The ruleset as JSON |
| `flags:import <file> [--env] [--note]` | Replace a ruleset (validated; approvals apply) |
| `flags:promote <from> <to>` | Copy one environment's ruleset over another |
| `flags:stale [--unused-days] [--static-days]` | Flags that are probably safe to remove |
| `flags:refs [--flag]` | Where each flag is used in the code |
| `flags:replay <sink>` | Deliver the retained event log to a sink again |
| `flags:forget <subject>` | Delete everything stored about a subject |

Commands act as `cli:<your OS user>` in the audit; `--as` overrides it.
